# Lucky Ordering API

Cloudflare Workers API for a Luckin Coffee proxy ordering system.

The service uses Hono, Chanfana, D1, and Vitest. It exposes POST-only CRUD routes so every operation receives parameters from the JSON request body.

## Data Model

### `lucky_order_users`

Stores Luckin users that can place real orders.

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `TEXT` | 10-character `a-zA-Z0-9` id generated by the API |
| `nickname` | `TEXT` | User nickname |
| `token` | `TEXT` | Luckin token |
| `type` | `TEXT` | Defaults to `lucky` |
| `status` | `TEXT` | `enabled` or `disabled`, defaults to `enabled` |
| `is_delete` | `INTEGER` | Soft delete flag, defaults to `0` |

### `lucky_sellable_products`

Stores product information that can be used for proxy ordering. Third-party fields are optional values that may arrive with a third-party order push.

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `TEXT` | 10-character `a-zA-Z0-9` id generated by the API |
| `sellable_product_ids` | `TEXT` | JSON string array in D1, array in API responses |
| `sellable_sku_codes` | `TEXT` | JSON string array in D1, array in API responses |
| `sellable_quantity` | `INTEGER` | Defaults to `1` |
| `status` | `TEXT` | `waiting`, `pending`, or `done`, defaults to `waiting` |
| `order_user_id` | `TEXT` | Active `lucky_order_users.id` |
| `third_party_remark_id` | `TEXT` | Optional 3-character `a-zA-Z0-9` value |
| `third_party_order_id` | `TEXT` | Optional third-party order id |
| `third_party_product_id` | `TEXT` | Optional third-party product id |
| `is_delete` | `INTEGER` | Soft delete flag, defaults to `0` |

## Routes

All routes use `POST` and JSON bodies.

### Order Users

- `POST /order-users/list`
- `POST /order-users/create`
- `POST /order-users/read`
- `POST /order-users/update`
- `POST /order-users/delete`

### Sellable Products

- `POST /sellable-products/list`
- `POST /sellable-products/create`
- `POST /sellable-products/read`
- `POST /sellable-products/update`
- `POST /sellable-products/delete`

## Development

Install dependencies:

```bash
npm install
```

Apply local D1 migrations:

```bash
npm run seedLocalDb
```

Run tests:

```bash
npm test
```

Start local development:

```bash
npm run dev
```
